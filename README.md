# Chess Game in Java
## Description
Development of a chess game in Java, complete with all official rules, including special moves (castling, pawn promotion, and en passant). The graphical interface was developed using ZGL. The game also features a bot using the minimax algorithm with alpha-beta pruning.
## Technologies Used

Java
ZGL (Zuccante Graphics Library)

## Features

All official chess rules
Special moves (castling, en passant, pawn promotion)
Graphical interface inspired by chess.com
Bot with minimax algorithm and alpha-beta pruning

## How to Run

Open the project in your IDE (IntelliJ / Eclipse)
Run Main.java
